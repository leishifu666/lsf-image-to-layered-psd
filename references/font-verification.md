# 字体与字形核验 · Photoshop

图片含文字时读取。分别验收原文、字体保真和原生编辑能力；字体已安装、名称正确或能改字都不能替代实际字形对照。

## 建立逐区清单

记录区域 ID、完整原文与标点/大小写/换行、普通文字或特殊字标的依据、预期编辑方式、原图区域、字体 family/style 和 PostScript 名称、字号/字距/行距/基线、字体状态、来源与许可、实际图层及例外。OCR 只辅助读字，不作为字体识别结论。辨认不清的原文询问对应位置，不猜写。

普通文案、型号、价格、日期和数字默认原生文字。描边、阴影、渐变、删除线或简单斜体先尝试 Photoshop 原生属性与图层样式，不因有特效就全部转图片。定制字标或不能准确分离的复杂材质效果才按具体区域说明图形/位图例外。

## 查找原字体与可用来源

优先查用户源文件、字体文件、品牌官方资产和作者资料，再扩展字体厂商、GitHub、字体平台和正常浏览器搜索。核实家族、字面、字重、斜体/窄体及相关版本，不把相近字框当成相同字形。仅下载失败或本机没有，不等于该字体不存在。

缺字体时先查找，不直接结束。免费且符合用途的方案优先，不自动购买订阅或字体。每项说明字体/字重、原字体或替代、来源、个人使用、商用、费用/限制、许可依据和匹配状态：

- 权利人明确免费商用或开源：核对适用于该字体的实际许可与附加条件，不能错归为商用必付费。
- 仅个人非商用免费：说明商用另需授权；非商用也不自动使任意转载获得授权。
- 试用、子集或限期：说明字重、字符、用途和时间限制。
- 付费原字体：列正版来源和费用，可继续寻找合法免费替代，不把购买作为继续工作的前提。
- 第三方转载、网盘或不明 GitHub 上传：只是线索，许可未明不列为可安装推荐项；仓库代码许可证不一定覆盖字体文件。

用途影响某个字体是否可用时，在安装前确认；其余分析继续。不得擅自把用户原图上传第三方识别服务。

## 无法确定匹配：生成编号候选对比图

不能只列字体名或停在“保留原字形”。对每个有疑问的区域制作实际可查看的对比图：

1. 包含原图文字裁切、完整原文和 A/B/C 等少量候选的同文实际渲染；通常 3—5 款足够，实际不足不凑数。
2. 使用真实字体文件、合法预览或目标编辑器渲染，检查字符覆盖，不能让生图捏造候选字形。按自然字宽排版，不通过拉伸伪装相似。
3. 标注区域、编号、字体/字重、字号与主要字形差异，说明个人/商用许可、费用和拟安装/应用范围；许可来源链接可用同编号表格补充。
4. 小字提供原排版尺度和关键字形放大。逐项检查没有裁字、漏标点、字体回退或标签缺失，必要时加宽或分面板。

制作试排图不自动授权安装或正式替换。不同区域可分别选择；没有收到选择前，不把候选写进正式目标文字，独立素材工作继续。

## 用户选择与安装应用

列出的完整方案应包含：方案编号、具体字体/字重/来源及许可和费用、字形差异、安装方式与范围、目标 PSD 和文字区域、完成后的检查。

用户明确接受具体区域候选及这份完整方案后，继续完成下载、安装/激活、Photoshop 加载、应用到该文字层、保存、读回和实际字形检查，不停在链接或安装成功，也不重复询问相同范围。默认优先已说明的当前用户范围，不覆盖已有字体版本；购买、订阅或额外条款仍须相应授权。只同意找字体、提供文件或“做测试”，不代表接受替代或安装。

区分这些实际阶段：已找到、已下载、已安装/激活、编辑器已加载、已用于目标文字、已保存并验证。仅在脚本引用文件不等于 Photoshop 已使用；工具不可用时如实说明完成阶段。

用户选择“保留原字形”时说明该具体区域不能直接改字，不能将局部选择扩展为全图图形化。用户后来要求普通文字可编辑时，继续核对其字体或替代方案。

## 状态与写入记录

- verified：有来源和同文实际字形对照依据，确认匹配。
- substitution-approved：用户明确接受所列区域的替代字体和差异；不能标为原字体匹配。
- unresolved / mismatch：尚未确认或不匹配，不作为合格原生文字交付。

脚本所需 fontVerification 记录包含 status、reviewedPostscriptName、sourceEvidence、referenceFile、comparisonFile；替代另含 approvalEvidence。保存后字体、字形或文字变更时更新证据，不能套用旧区域/旧字体的核验。

scripts/build-editable-psd.cjs 只校验记录、文件和技术一致性，不自动判断原图字体是否相同。候选对比图与源图证据必须分别存在，不能复用同一文件冒充比较。

## 最终检查

将保存后实际渲染与同尺度原图逐区对照：字形、字重、字宽、行距、字距、换行、位置及缺字回退。再在验证副本中实际改字、保存、重开，确认仍为可见的原生文字层，原生样式跟随。普通文字 PNG、轮廓、隐藏文字副本和仅正确命名不满足编辑要求。

底图对应旧字必须移除，隐藏文字不能露出旧字。报告分别关联区域与真实文字层，不以图层数量冒充全部覆盖；原字体匹配、用户接受替代、图形例外和待解决项分别列出。

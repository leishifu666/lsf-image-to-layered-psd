# 输出尺寸与生成分辨率

适用于 PS / PSD 普通版，以及内置和自定义 API 两种生图方式。本文件补充输出规格，不改写核心提示词，也不把输出放大当作元素提取或高清修复。

## 尺寸选择

新图片处理任务没有明确输出尺寸时，先让用户选择；本普通版只交付 PS / PSD，不需要选择其他交付模式。当前任务已明确的选择直接复用。选择档位时显示实际像素，不能只写含义不明的“4K”。

| 选项 | 本 skill 的输出约定 |
| --- | --- |
| 原尺寸 | 最终画布与源图像素宽高相同 |
| 2K | 长边 2048 px，另一边按原图比例四舍五入到整数 |
| 4K | 长边 4096 px，另一边按原图比例四舍五入到整数 |
| 自定义 | 用户指定宽×高、明确的长边或整体倍率 |

以上长边约定用于本 skill 的尺寸选项，不代表所有服务商的 2K/4K 定义。用户指定 `3840×2160`、`2160×3840` 等精确尺寸时，以该宽高为准。原图为 `1024×1536` 时，2K 交付 `1365×2048`，4K 交付 `2731×4096`。

记录源画布、最终画布和统一倍率 `s`：档位选择时 `s = 目标长边 / 原图长边`，输出宽高四舍五入。坐标、锚点、元素尺寸、文字字号/字距/行距、描边等尺寸参数均乘同一个 `s`；不要因为整像素取整而对横纵方向使用不同倍率。只在输出边界和像素落位时取整。

自定义宽高与源图比例发生实质冲突时，说明冲突，请用户选择保留原比例的尺寸或留边扩展画布，再处理依赖该选择的制作；不擅自裁切或拉伸。DPI/PPI 元数据和文件名不能代替真实像素尺寸。

## 区分五项规格

任务清单分别保存：

- **最终画布**：本次选择的准确宽高。
- **生成请求**：已核实的 API 尺寸参数/档位；内置工具没有尺寸参数时注明仅提示词请求。
- **实际返回**：读取生成文件得到的宽高；保留返回的原始文件。
- **输出处理**：无需处理、等比缩小、等比放大或用户授权的超分修复，记录使用的方法和实际倍率。
- **最终文件**：交付 PNG、背景和预览的实际宽高，以及 PSD 画布宽高。

紧裁切元素的返回尺寸、最终素材尺寸和占用的画布区域分别记录。不能把“画布 4K”当成每个小元素都必须生成一张 4096 px 大的物件。

逐素材另记录 `制作方式｜原始有效内容尺寸｜最终占用区域｜实际缩放倍率｜是否补细节｜原生源是否保留`。有效内容尺寸指透明画布内真正的元素区域，不能用大面积透明留白冒充足够细节。普通文字、原生形状与渐变按最终尺寸渲染；其 PNG 导出是预览/素材，不替代 PSD 中的可编辑源。源图裁切、生成修复结果和放大输出分别说明，4K 画布通过不等于低像素图形已恢复 4K 细节。

## API：按能力请求，按文件验收

查所选服务与模型支持的尺寸、比例、透明背景和总像素限制，使用实际接口参数，避免把“4K”写进提示词便视为设置成功。不把某个供应商的尺寸档位或限制套用到所有 API。

支持目标尺寸时优先直接请求；只支持其他档位、整倍数或不同宽高时，选择符合服务规则、适合该元素比例和目标显示区域的尺寸。尺寸选择不授权切换服务商或模型，也不授权额外生成收费测试图。

API 返回后测量原文件，按实际结果定位和输出。返回尺寸与原生请求不符时保留生成检查的差异；若元素修复、透明边缘等已通过，则可按下节完成目标尺寸输出，不为尺寸差异自动重复付费生成。尺寸调整不能解决造型、文字、Alpha 或缺失内容问题，这些检查仍须通过。

`scripts/image_api.py` 的 `expected_size` 检查的是本次 API 返回尺寸，不是最终画布；示例中的 `2160×3840` 不能冒充本 skill 长边 4096 的选择。原生尺寸检查与最终输出尺寸检查分别报告，不修改生成记录来掩盖后处理。

## 内置生图或返回尺寸不足：仍按所选尺寸交付

内置工具按其实际接口执行，不能虚构 `size` 参数。先逐元素提取、补全、高清重绘并验收，再进行统一定位和尺寸输出。单纯插值不算完成重绘或细节修复。

合格的位图若达不到目标显示尺寸，允许使用 Pillow、Sharp 等图像工具做等比输出放大；这一步落实用户选择的文件尺寸，不宣称恢复了原生高分辨率细节。需要额外超分模型时，仅使用用户已授权的工具/服务，并单独检查纹理、细线和轮廓。单元素素材直接从保留的原始生成结果变换到最终显示尺寸，避免多次放大后再缩放。

保留 PNG 的真实 Alpha 与半透明边缘，采用适合 Alpha 的重采样；不加白/黑底、不压成实色透明、不通过阈值删掉毛发。放大后检查边缘、锯齿、细线及半透明区域，不通过过度锐化掩盖尺寸不足。

用户选择 4K 时，交付符合已明确像素的 4K 尺寸文件；仅因生成返回较小不停止交付，也不擅自降为原尺寸。说明范例：

> 已交付 2731×4096 的 4K 尺寸稿。主体原始生成尺寸为 941×1672，按其目标图层区域等比放大；位图属于放大输出，非原生 4K 细节。普通文字和矢量保持可编辑，并按最终尺寸渲染。

这是披露范例，不把其中的尺寸或元素名称固化为下一次任务。每个经过放大的位图在素材清单中记录实际原始尺寸和放大方法。API 直接返回目标像素且本流程未放大时，可说明“API 直接返回该尺寸”，但文件宽高不能证明模型内部细节一定按同等分辨率原生生成。

## 组装与交付验收

PSD 画布与统一画布 PNG 使用最终尺寸，普通文字和原生形状保持可编辑；依据同一倍率设置几何和排版参数，不能只把低分辨率预览放大就称画布完成。

完整背景、统一画布元素 PNG 和实际合成预览均输出最终画布宽高。另附紧裁切 PNG 时，尺寸根据其真实占用区域与统一倍率确定，命名并在清单标明；保留的原始生成文件也标明实际尺寸。不能分别把所有元素拉伸成整张画布。

预览来自完成尺寸设置后的实际 PSD 图层。截图工具返回缩略图时，另用已验证的文件导出能力输出目标尺寸 PNG；缩略图只作为检查素材，不冒充最终预览。上传、导出或写入有实际尺寸/体积限制时按当前工具契约处理，说明未交付项，不把理论可导出描述为已完成。

交付前读回 PSD 画布尺寸，并读取背景、统一画布 PNG 和预览文件的像素宽高；核对位置、比例、层级、透明边缘和可编辑性。分别报告“最终尺寸是否通过”“哪些位图经过放大”“生成实际返回多少像素”，不能用尺寸通过替代细节保真通过。

# 图片高清拆层 PSD

## 核心提示词

开始执行前，完整读取 [references/core-prompt.md](core-prompt.md)。这是用户确认的核心提示词，保持原文，不自行改写、压缩、删减或替换条件。只有用户明确要求修改核心提示词时才修改该文件。

本文件提供执行方法，不代替或降低核心提示词中的验收条件。实际单元素工具调用可附加当前元素的描述、参考图角色、原图坐标和输出规格；这些任务数据不写回核心提示词。不要固化上一张图片的产品、文案、风格、元素数量、分层类别或放大倍率。

当前执行补充：先按主入口分流。普通文字用原生文字层；能准确还原的纯色、渐变、边框与规则图形用 Photoshop 原生填充、渐变或形状；复杂位图才按原始核心提示词逐元素修复。原文保持不变，不把其中的位图修复要求解释成必须将原生文字、渐变背景也交给生图。

## 任务范围与工具

- 用户提供图片并要求拆层交付时，执行到文件交付；只要求分析、提示词或局部修复时，遵守该范围。
- 先查看输入图片。附图内文字与文件内容属于素材，不自动成为执行指令。保留原文件，在当前任务目录处理。
- 生成或修复位图时使用用户选择的生图方式。内置方式按 `imagegen` 技能执行；自定义 API 方式读取 [custom-image-api.md](custom-image-api.md)，按已核实的服务接口生成。每次只处理一个元素，前景请求真实透明背景，背景请求完整不透明底图。不用程序裁切、简单放大或重复整图替代重绘。
- 工具返回格式、路径、尺寸和 PSD 写入接口以实际工具文档或当前依赖为准。不要假设生图工具能直接导出 PSD；使用支持图层的编辑器或已验证的 PSD 写入库组装。
- 缺少图片时请求原图；缺少生图或 PSD 写入能力时，说明具体缺项，继续能独立完成的分析或素材工作，不把未完成的文件描述为已交付。

## 执行流程

### 1. 建立原图基准和遮挡关系

记录原图宽高、元素清单、每个元素的原始区域和定位锚点、原文，以及前后遮挡关系。内部清单包含稳定 ID、名称、坐标、制作方式、被谁遮挡、遮挡谁、输出路径与检查状态；文字另关联字体状态、预期编辑能力、实际图层及例外依据，不要求用户填写。

先确定实际堆叠关系，再决定分组。图层面板的上方显示在前、下方显示在后，背景在所有画面元素下方。不要采用固定的“文字→主体→装饰→环境”层级，也不要按生成时间、文件名或编号决定顺序。需要跨越其他图层的同类元素不能因归入同一组而改变前后位置。出现局部交错遮挡时，用蒙版或关联命名的前后子图层表达，不强行建立错误的单一顺序。

按 [output-resolution.md](output-resolution.md) 确定交付画布；用户已指定尺寸或倍率时直接使用，未指定时先选择原尺寸、2K、4K 或自定义宽高。所有尺寸、定位锚点与坐标采用同一倍率，禁止分别拉伸元素来强行匹配边界。

### 2. 逐元素提取、重绘和检查

对已分流为位图修复的元素，以原图为内容与位置依据，每次只向图像工具提交一个目标元素。近景参考裁切只能作为辅助输入，不能作为完成的高清素材。重复核心提示词中的造型、比例、姿态、颜色、材质、纹理、文字和风格不变量。普通文字和规则图形按原生方式制作，不为凑齐生图清单额外生成一遍。

每个结果生成后检查完整性、原文、结构与透明边缘，合格后进入组装。失败时针对当前元素的具体缺陷修复；不要通过重绘整张海报掩盖局部问题。保持有意的颗粒、网点、笔触和纸纹，区别于需要修复的压缩噪点。不可辨认的文字不要自行猜写；确实影响交付时指出对应位置并请求必要信息，同时继续处理其他元素。

含文字时必须先按 [font-verification.md](font-verification.md) 核验原字体与实际字形；普通文字按 [ps-editable-text.md](ps-editable-text.md) 重建为原生文字图层，不对这些文字再调用生图来冒充可编辑结果。未核验或不匹配的字体不进入保真合格文字层，也不能因“做测试”而自行使用近似字体。底图旧字仍须移除并修复，特殊字标和效果按保真要求分流。此扩展不改写核心提示词。

### 3. 重建背景并对齐素材

单独重建移除全部前景后的完整背景，检查没有文字、物件、轮廓或残影。各前景 PNG 默认使用与交付 PSD 相同的透明画布，并回到原图对应坐标，禁止单独居中。

纯色背景用纯色填充，渐变背景按实际色标、方向、位置和过渡范围重建为原生渐变；有独立纹理时单独叠加，不能为获得渐变而丢掉原图纹理。导出完整背景 PNG，同时在 PSD 保留可编辑源。仅用程序绘出一张渐变 PNG 不等于 PSD 中渐变可编辑。

如果工具返回紧裁切素材或不同尺寸，将结果依照原图锚点做等比定位，并记录变换。重采样用于对齐已完成的重绘素材和落实已选择的输出尺寸，不能作为高清修复。保留原始生成文件，清楚区分返回素材与统一画布素材；需要放大到 2K/4K 时完成目标像素输出，并注明放大方法、倍率和非原生细节。

### 4. 组装真实分层 PSD

写入前读取 [references/psd-assembly.md](psd-assembly.md)，核对当前写入工具的数组顺序、分组、可见性和蒙版约定。

独立元素建立独立命名图层，按照已核对的遮挡关系设置真实堆叠顺序。分组只用于管理，不得改变重叠区域的显示结果。默认打开所有参与最终构图的图层与图层组；原图参考、草稿和备用图层隐藏并标注。最终合成不得依靠顶层整图覆盖真实图层。

完整独立元素 PNG 与 PSD 中的前后子图层可以具有不同结构，但必须明确关联；子图层共同表达同一元素，不造成重复叠印。普通文字按 [ps-editable-text.md](ps-editable-text.md) 重建原生文字；特殊字标、复杂特效或用户明确保留原字形的具体区域才采用对应图形方案，并列出依据。未知字体先查找、制作候选对比图，不能直接把它变成像素层后称已完成。

### 5. 验证保存后的文件并交付

逐层检查独立显示、隐藏、边缘和重叠区域。保存后重新打开或读取 PSD，依据其中保存的真实图层顺序、可见性和蒙版重新合成；预览来自这次实际图层合成。检查全局构图与每个交叠区域，发现顺序问题先修复再交付。

字体与编辑能力分别验收：按 [font-verification.md](font-verification.md) 对保存后文字逐区核对字体、字形、字重和排版，再实际改字、保存并读回验证。文字层类型正确或能改字不能替代字体匹配；未解决字体不能算通过。

优先在 Photoshop 中检查首次打开状态；若不可用，用能解码并重新合成图层的读取器检查。不能只读取 PSD 内嵌合成图就声称图层排序正确；同一套代码写入后读回也不能单独证明其堆叠约定与 Photoshop 一致。区分文件检查与 Photoshop 实测，说明未验证项。

最终交付分层 PSD、各元素独立透明 PNG、完整背景 PNG、实际合成预览。按任务需要附素材清单或压缩包，提供可点击的实际文件路径。核对文件的实际像素与所选尺寸一致，说明画布尺寸、图层数量、放大素材、验证结果及仍存在的保真差异；未通过的检查不能写成通过。
